## Independent review and limits

No blocking baseline-code finding remains. The original lead design was narrowed before any measurements to remove an invalid encoder-cost claim. Documentation was corrected before the preregistration freeze. The immutable preregistration hash is 543e0b0a3a9eb8e179329814f7e45b36146103471644133efa72bef1b0c785ee.

Fairness limits: metadata is an explicit accounting model rather than a serialized format; actual Python object and allocator costs are excluded. Method order is fixed, there is no explicit warmup, and timing is descriptive only. Exact dedup retains a full-byte verification reference during encoding; its encoder working memory is not part of stored-byte accounting. Generated families do not predict real workload frequencies. Random inputs are deterministic pseudorandom bytes, not a proof about all random strings. Future comparisons must retain these baselines, seeds and hashes.
